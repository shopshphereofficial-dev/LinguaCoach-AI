# LinguaCoach AI 🎓

A Duolingo-style **multi-language learning app for Android**, built with
**Flutter** and powered directly by the **Google Gemini API**. There is no
backend — every request goes straight from your device to Gemini.

**New in v2.0.0 — a real course, not just a chat.** Every language now has a
guided **learning path** of 20 lessons across 5 units, each lesson ending in a
short **live voice chat with your teacher** about that exact topic.

---

## 🗺️ The learning path

Open a language and you get a structured course instead of a blank chat box:

| Unit | Level | Lessons |
| --- | --- | --- |
| **1 · Foundations** | Beginner | Greetings & introductions · Numbers & counting · Days, time & dates · Family & people |
| **2 · Everyday life** | Beginner | Food & drink · Shopping basics · Home & daily routine · Weather & seasons |
| **3 · Getting around** | Intermediate | Directions & transport · At the restaurant · Health & the body · Making plans |
| **4 · Social & work** | Intermediate | Work & study · Hobbies & free time · Describing people & feelings · Opinions & small talk |
| **5 · Confident speaker** | Advanced | Travel & hotels · Problems & emergencies · Culture & news · Idioms & natural speech |

Lessons unlock in order, like levels in a game. Each one is a **5-step loop**:

1. **Learn** — 6 new words with example sentences and audio.
2. **Sentences** — 4 example sentences with translations.
3. **Practice** — 5 mixed exercises (multiple choice, fill-in-the-blank,
   translation, listening) with explanations.
4. **Speak** — say the lesson's speaking task out loud and see your transcript.
5. **Live** — a real-time voice chat with your teacher focused on that topic.

Finishing a lesson earns **1–3 stars** (based on your quiz score) and XP, and
unlocks the next one. The path shows your progress per unit and overall.

Lesson content is generated by Gemini **once per language + lesson and cached on
the device**, so a lesson you have opened before is instant and works offline.

## 🎓 Live classes with animated teachers

The Live API (WebSocket, streaming audio both ways) powers a genuine
conversation: you just talk, the teacher answers within a fraction of a second,
and **you can interrupt them** at any time.

| Teacher | Style | Languages | Voice |
| --- | --- | --- | --- |
| **Aanya** | Warm & encouraging | Hindi · English | Aoede |
| **Marco** | Energetic & fun | Spanish · Italian | Puck |
| **Yuki** | Calm & precise | Japanese · Korean | Kore |
| **Layla** | Friendly & expressive | Arabic · French | Leda |
| **Sofia** | Cheerful & clear | Portuguese · German | Zephyr |

Pick your teacher on the Home tab or in Settings. You can switch language and
teacher from inside a live class.

**The avatar** is drawn entirely in code (`TeacherAvatar`), so it needs no image
assets and stays sharp at any size. It reacts to the live audio:

- **Lip sync** — the mouth opening follows the loudness of the teacher's voice
  frame by frame, and the chin drops with it so the whole jaw moves.
- **Head** — nods slightly on loud syllables and tilts while listening.
- **Hair** — trails the head with a phase lag, so it moves rather than sticking
  to the skull.
- **Eyes** — natural random blinks, occasional double blinks, and small gaze
  shifts so the teacher does not stare.
- **Body** — gentle breathing and a shoulder bob while speaking.

## 🔑 API key configuration

The app ships **with the API key already configured**, so there is no setup
screen. The key is not in the source code; it is injected at compile time from a
repository secret:

```
flutter build apk --release --dart-define=GEMINI_API_KEY="$GEMINI_API_KEY"
```

In CI this comes from the **`GEMINI_API_KEY`** repository secret
(*Settings → Secrets and variables → Actions*). To rotate the key, update that
secret and re-run the workflow.

A user can still paste their own key in *Settings*; it takes priority and is
stored with `flutter_secure_storage`. The key is always shown masked.

> **Security note.** Anything embedded in a client app can be extracted from the
> APK. For production, put the key behind a backend/proxy or use ephemeral
> tokens (which the Live API supports) instead of shipping it in the app.

### Models

**Live voice:** `gemini-3.8-live` (default), `gemini-3.1-flash-live-preview`,
`gemini-2.5-flash-native-audio-latest`.

**Text:** `gemini-flash-latest` (default), `gemini-pro-latest`,
`gemini-flash-lite-latest`, `gemini-3.8/3.7/3.6/3.5-flash`,
`gemini-3.1-flash-lite`.

## 🛠️ Building it yourself

```bash
git clone https://github.com/shopshphereofficial-dev/LinguaCoach-AI.git
cd LinguaCoach-AI

flutter create --platforms=android --org com.linguacoach --project-name lingua_coach_ai .
python3 .github/scripts/patch_android.py    # permissions, minSdk 23, icons

flutter pub get
flutter run --dart-define=GEMINI_API_KEY="YOUR_KEY"
flutter build apk --release --dart-define=GEMINI_API_KEY="YOUR_KEY"
```

Requires Flutter 3.24+ and JDK 17. minSdk is 23 (the live-audio plugin needs
it). Without the `--dart-define` the app falls back to a welcome screen asking
for a key.

## 📁 Project structure

```
lib/
├── main.dart                     # app entry + provider wiring
├── config/app_config.dart        # build-time API key / model
├── models/                       # Language, Teacher, curriculum (path),
│                                 # LessonContent, ChatMessage, QuizQuestion,
│                                 # Lesson, RolePlayScenario, UserProgress, …
├── services/
│   ├── gemini_service.dart       # all text REST calls + system prompts
│   ├── curriculum_service.dart   # loads + caches lesson content for the path
│   ├── live_session_service.dart # Gemini Live API over WebSocket (voice)
│   ├── audio_io_service.dart     # 16 kHz mic capture + 24 kHz PCM playback
│   ├── storage_service.dart      # secure key storage + preferences
│   └── speech_service.dart       # speech-to-text + text-to-speech
├── providers/                    # settings + progress (XP, stars, path)
├── screens/                      # 19 screens (path, lesson player, live class…)
├── widgets/
│   ├── teacher_avatar.dart       # animated, lip-syncing avatar (CustomPainter)
│   ├── app_logo.dart             # logo mark, drawn in code
│   └── common.dart               # shared UI pieces
└── theme/app_theme.dart
```

- The Live API needs a real device or an emulator with a working microphone.
- All AI output is generated by Gemini and can occasionally be imperfect.
- The CI APK is debug-signed: fine for sideloading, **not** for the Play Store.
